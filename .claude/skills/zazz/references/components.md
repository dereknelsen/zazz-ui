# Zazz component API index

The stable **API surface** only — selector, `data-*` attributes and their accepted values,
what powers the component, and where the canonical example lives. **No example markup is
copied here** (that would duplicate the single source). To author a component, fetch the real
markup from the docs page or read `packages/core/src/primitives/{name}/*.html` in-repo, then adapt it.

Variants/sizes follow the shadcn-style pattern: a `data-*` attribute reassigns the
component's local tokens (see `packages/core/src/primitives/button/button.css`). The **default** variant is the
_absence_ of the attribute.

Roots are the tag form (`<ui-tooltip>`) or its equivalent class form (`.ui-tooltip`) — both
spellings shown are interchangeable. Interior parts ("slots" below) are
`data-slot="{component}-{part}"`; the attribute is a **space-separated token list** (like
`class`), so selectors always use `[data-slot~="…"]`, and one element can serve two primitives
at once (`data-slot="lightbox-slide carousel-slide"`). Roots never carry `data-slot`.

## Forms

All field types share `--ui-field-*` tokens (`fields.css`, the Tier-3 owner). Wrap a control in
`.ui-field` (supports `data-orientation="horizontal"`) for the label / control / hint / error
layout. Validation surfaces via `:user-invalid` — **after** blur/submit, never while typing.

## Behaviors (not components — see `apis.md`)

- **`[popover]` (base)** — `data-side`/`data-align` positioning powers tooltip, menu, and
  navigation-menu; dark "inverted" popovers come from a container `style()` query.
- **Web components** (`<ui-carousel>`, `<ui-lightbox>`, `<ui-password>`,
  `<ui-tabs>`, `<ui-toaster>`) are light-DOM progressive enhancements; use the real
  examples as the source of truth.
- **Reveal** (`[data-reveal]` / `[data-reveal-each]`) and **Embla** (`data-carousel-*` config
  on the carousel root + `data-slot="carousel-*"` roles) are data-attribute-driven JS
  behaviors. Their full attribute catalogs are in `apis.md`.

> Trust this index + the variant selectors in each component's stylesheet
> (`packages/core/src/primitives/{name}/{name}.css`) for the real API, and the real example
> markup (`packages/core/src/primitives/{name}/*.html`) for structure. If an example ever shows an
> attribute with no matching stylesheet selector, the selector wins.
