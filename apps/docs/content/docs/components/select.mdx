---
title: Select
description: Native select control styled using the customizable select API and anchor positioning.
---

`.select` styles native `<select>` controls using `appearance: base-select`. Falls back to the standard OS dropdown where unsupported.

Requires a `<button><selectedcontent></selectedcontent></button>` as the first child of the `<select>` to serve as the trigger and mirror selection.

## API

| Attribute    | Target    | Values                           |
| ------------ | --------- | -------------------------------- |
| `data-side`  | `.select` | `top`, `bottom`, `left`, `right` |
| `data-align` | `.select` | `start`, `center`, `end`         |
