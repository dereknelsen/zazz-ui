title: Badge

---

Badges use the `.badge` class. Set colors with `data-variant` (default when omitted). Set `data-size="icon"` for square icon badges.

Badges can be static `<span>` elements or interactive `<button>` / `<a>` elements with hover/active states and disabled styling.

## API

| Attribute      | Values                                               |
| -------------- | ---------------------------------------------------- |
| `data-variant` | `primary`, `muted`, `ghost`, `link` (omit = default) |
| `data-size`    | `icon`                                               |

To apply status colors, override component tokens:

```html
<span
  class="badge"
  style="--badge-background: var(--success); --badge-foreground: var(--success-foreground)"
>
  Active
</span>
```
