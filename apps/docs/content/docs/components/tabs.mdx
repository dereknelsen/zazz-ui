---
title: Tabs
description: CSS-driven tabs using radio buttons with keyboard enhancement via ui-tabs.
---

Tabs use grouped `input[type="radio"][role="tab"]` inputs to toggle panels and sliding indicators using pure CSS. Wrap in `<ui-tabs class="tabs">` for keyboard navigation (arrow keys, Home/End, wrap-around). Radio button order must match tab panel order.

## API

| Attribute / Element | Placement | Values                             |
| ------------------- | --------- | ---------------------------------- |
| `<ui-tabs>`         | Root      | Custom element hosting `.tabs`     |
| `data-orientation`  | Root      | `vertical` (horizontal by default) |
