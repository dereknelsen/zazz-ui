---
title: Textarea
description: Multi-line text inputs with auto-growth and shared form field tokens.
---

`.ui-textarea` shares `--ui-field-*` tokens and `:user-invalid` validation states with the form input family. It applies `field-sizing: content` to auto-expand with text input, clamped between `--ui-textarea-min-block-size` (`5lh`) and `--ui-textarea-max-block-size` (`12lh`).
