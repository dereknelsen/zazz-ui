---
title: Input group
description: Input fields with attached leading, trailing, top, or bottom addons.
---

`.input-group` wraps an `.input` with `[data-slot="input-group-addon"]` elements. Position addons using `data-align`.

<Preview src="input-group/default" />

## Password group

Wraps inputs in `<ui-password>` to provide a password visibility toggle:

<Preview src="input-group/password-group" />

## API

| Attribute    | Target                            | Values                                                   |
| ------------ | --------------------------------- | -------------------------------------------------------- |
| `data-align` | `[data-slot="input-group-addon"]` | `inline-start`, `inline-end`, `block-start`, `block-end` |
