Buttons use the `.button` class on `<button>` or `<a>` elements. Choose styles with `data-variant` and dimensions with `data-size`. Omitting `data-variant` applies the default style.

## With keyboard shortcuts

Add a `<kbd>` element inside the button for shortcut keys:

```html
<button class="button">Search <kbd>Cmd+K</kbd></button>
```

## API

| Attribute      | Values                                                              |
| -------------- | ------------------------------------------------------------------- |
| `data-variant` | `primary`, `muted`, `ghost`, `destructive`, `link` (omit = default) |
| `data-size`    | `sm`, `icon`, `icon-sm`                                             |

Customize buttons globally by overriding `--button-background`, `--button-radius`, `--button-height`, etc. on `:root`.
