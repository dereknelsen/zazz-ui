---
title: Avatar
description: Circular image with fallback composed using utility classes.
---

Avatars are composed with utility classes. Stack an image over fallback text using `grid grid-area-pile`, clip with `rounded-full overflow-clip`, and set dimensions with `size-*`.

Fallback text (`bg-muted`, `text-muted-foreground`) shows if the image fails to load. For text-only avatars, omit the `<img>` element.
