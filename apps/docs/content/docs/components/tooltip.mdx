title: Tooltip

A tooltip connects a trigger button with `.tooltip__content` (`popover="hint"`) via `interestfor` on the trigger. Handles hover, focus, and long-press automatically.

## API

| Attribute                | Target              | Values                           |
| ------------------------ | ------------------- | -------------------------------- |
| `interestfor`            | Trigger             | ID of `.tooltip__content`        |
| `data-side`              | `.tooltip__content` | `top`, `bottom`, `left`, `right` |
| `data-align`             | `.tooltip__content` | `center`                         |
| `data-use-inverted-menu` | `.tooltip__content` | `false`                          |
