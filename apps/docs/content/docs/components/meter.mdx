---
title: Meter
description: A scalar value within a known range on a native meter element.
---

A native `<meter class="ui-meter">` element, styled to read as the [Progress](/docs/components/progress) bar's sibling — geometry aliases the `--ui-progress-*` family. Where progress communicates completion, a meter communicates good/bad: the fill is `--success` in the optimal region and shifts to `--warning` / `--destructive` as the value crosses `low`/`high` relative to `optimum`. Always include fallback text content and a label.

Engines that support typed `attr()` paint the fill on the element itself from the meter's own attributes (Blink locks its shadow parts' geometry); elsewhere the vendor fill pseudos carry the colors.

## API

| Attribute                  | Target      | Values                                             |
| -------------------------- | ----------- | -------------------------------------------------- |
| `value` / `min` / `max`    | `.ui-meter` | Native meter semantics                             |
| `low` / `high` / `optimum` | `.ui-meter` | Region thresholds — drive the fill color           |
| Tokens                     | `:root`     | `--ui-meter-*`; geometry aliases `--ui-progress-*` |
