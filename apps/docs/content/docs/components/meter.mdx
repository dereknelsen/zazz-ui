---
title: Meter
description: A scalar value within a known range on a native meter element.
---

A native `<meter class="ui-meter">` element, styled as a visual companion to the [Progress](/docs/components/progress) bar (its geometry aliases the `--ui-progress-*` tokens). Where progress communicates completion, a meter indicates quality or capacity. The fill color is `--success` in the optimal region and shifts to `--warning` or `--destructive` as the value crosses `low` or `high` relative to `optimum`. Always include fallback text content and a label.

Engines supporting typed `attr()` paint the fill on the element itself from the meter attributes (Blink locks its shadow parts geometry). Other engines use vendor fill pseudo-elements to carry the colors.

## API

| Attribute                  | Target      | Values                                             |
| -------------------------- | ----------- | -------------------------------------------------- |
| `value` / `min` / `max`    | `.ui-meter` | Native meter semantics                             |
| `low` / `high` / `optimum` | `.ui-meter` | Region thresholds that drive the fill color        |
| Tokens                     | `:root`     | `--ui-meter-*`; geometry aliases `--ui-progress-*` |
