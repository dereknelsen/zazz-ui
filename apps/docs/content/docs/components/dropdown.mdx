---
title: Dropdown
description: Popover menus using the Popover API, anchor positioning, and native light dismiss.
---

A dropdown uses `[data-slot="dropdown-popover"]` (`popover="auto"`) triggered by a button with `popovertarget`. Menu items use ghost buttons. Position with `data-side` and `data-align`.

## Default

<Preview src="dropdown/default" />

## API

| Attribute       | Target                           | Values                                 |
| --------------- | -------------------------------- | -------------------------------------- |
| `popovertarget` | Trigger                          | ID of `[data-slot="dropdown-popover"]` |
| `data-side`     | `[data-slot="dropdown-popover"]` | `top`, `bottom`, `left`, `right`       |
| `data-align`    | `[data-slot="dropdown-popover"]` | `start`, `center`, `end`               |
