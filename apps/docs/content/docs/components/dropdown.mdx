title: Dropdown

---

A `<ui-dropdown>` wraps a trigger button (`popovertarget`) and its `[data-slot="dropdown-popover"]` panel (`popover="auto"`). The class form `<div class="ui-dropdown">` is equivalent — the tag is CSS-only, no JavaScript involved. Menu items use ghost buttons. Position with `data-side` and `data-align`.

## API

| Attribute       | Target                           | Values                                 |
| --------------- | -------------------------------- | -------------------------------------- |
| `popovertarget` | Trigger                          | ID of `[data-slot="dropdown-popover"]` |
| `data-side`     | `[data-slot="dropdown-popover"]` | `top`, `bottom`, `left`, `right`       |
| `data-align`    | `[data-slot="dropdown-popover"]` | `start`, `center`, `end`               |
