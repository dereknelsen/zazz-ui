---
title: Dropdown
description: Popover menus using the Popover API, anchor positioning, and native light dismiss.
---

A dropdown uses `.dropdown__popover` (`popover="auto"`) triggered by a button with `popovertarget`. Menu items use ghost buttons. Position with `data-side` and `data-align`.

## Default

<Preview src="dropdown/default" />

## API

| Attribute       | Target               | Values                           |
| --------------- | -------------------- | -------------------------------- |
| `popovertarget` | Trigger              | ID of `.dropdown__popover`       |
| `data-side`     | `.dropdown__popover` | `top`, `bottom`, `left`, `right` |
| `data-align`    | `.dropdown__popover` | `start`, `center`, `end`         |
