---
title: Navigation menu
description: Mega-menu navigation using popover panels, nested submenus, and anchor positioning.
---

The navigation menu combines button triggers (`popovertarget`) with `.navigation-menu__popover` panels. `.navigation-menu__list` contains items and triggers. Panels contain a `.navigation-menu__viewport` grid of `.navigation-menu__link` items and optional `.navigation-menu__submenu` flyouts.

## API

| Attribute        | Target                      | Values                        |
| ---------------- | --------------------------- | ----------------------------- |
| `popovertarget`  | Trigger                     | ID of target panel            |
| `data-align`     | `.navigation-menu__popover` | `center`, `end`               |
| `data-variant`   | `.navigation-menu__popover` | `submenu`                     |
| `data-size`      | `.navigation-menu__popover` | `root`, `container`, `screen` |
| `data-animation` | `.navigation-menu__popover` | `slide-down`                  |
