---
title: Button group
description: Segmented button controls in horizontal or vertical layouts.
---

Wrap `.ui-button` elements in `.ui-button-group` to combine them into a single segmented control. The container squares inner corners and collapses borders. Add `role="group"` and `aria-label` for accessibility.

## Horizontal

Horizontal layout is the default:

<Preview src="button-group/default" align="center" />

## Vertical

Add `data-orientation="vertical"` to stack buttons:

<Preview src="button-group/vertical" align="center" />

## API

| Attribute          | Values                                 |
| ------------------ | -------------------------------------- |
| `data-orientation` | `vertical` (omit = horizontal default) |

Outer corners adapt to child button `--button-radius` tokens automatically.
