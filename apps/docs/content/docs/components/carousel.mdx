`<slide-carousel>` initializes an Embla carousel with markup-driven options, drag interactions, looping, keyboard navigation, and thumbnail synchronization.

## Default

## Anatomy

Define carousel structure with `data-carousel` roles. Set slide widths with `basis-*` utilities:

```html
<slide-carousel data-carousel-loop="true">
  <div data-carousel="viewport">
    <div data-carousel="container">
      <div data-carousel="slide" class="basis-full @sm:basis-1/2 @md:basis-1/3">Slide 1</div>
      <div data-carousel="slide" class="basis-full @sm:basis-1/2 @md:basis-1/3">Slide 2</div>
      <div data-carousel="slide" class="basis-full @sm:basis-1/2 @md:basis-1/3">Slide 3</div>
    </div>
  </div>
  <button type="button" data-carousel="prev">Prev</button>
  <button type="button" data-carousel="next">Next</button>
</slide-carousel>
```

| `data-carousel` | Role                                             |
| --------------- | ------------------------------------------------ |
| `viewport`      | Visible window (required)                        |
| `container`     | Flex track for slides                            |
| `slide`         | Individual slide item                            |
| `prev` / `next` | Navigation buttons (optional)                    |
| `dots` / `dot`  | Pagination container and template dot (optional) |
| `thumbs`        | Synchronized thumbnail container (optional)      |

## Setup

Load `index.js` as an ES module:

```html
<script type="module" src="./zazz/index.js"></script>
```

Third-party dependencies (Embla core and plugins) resolve through the `<script type="importmap">` in `<head>`.

## Options

Configure Embla options as `data-carousel-*` attributes on `<slide-carousel>`:

| Attribute                | Purpose                           |
| ------------------------ | --------------------------------- |
| `data-carousel-loop`     | Set to `"true"` for infinite loop |
| `data-carousel-align`    | `start`, `center`, or `end`       |
| `data-carousel-keyboard` | Set to `"false"` to disable keys  |

### Plugins

Enable plugins with boolean attributes:

```html
<slide-carousel data-carousel-autoplay data-carousel-autoplay-delay="3000">...</slide-carousel>
```

| Plugin      | Attribute prefix             | Package specifier            |
| ----------- | ---------------------------- | ---------------------------- |
| Autoplay    | `data-carousel-autoplay-*`   | `embla-carousel-autoplay`    |
| Auto Scroll | `data-carousel-autoscroll-*` | `embla-carousel-auto-scroll` |
| Class Names | `data-carousel-classnames-*` | `embla-carousel-class-names` |

## Dots pagination

```html
<div data-carousel="dots">
  <button type="button" data-carousel="dot"></button>
</div>
```

The script clones the template button for each slide and toggles `.is-active`.

## Thumbnail navigation

Nest a `data-carousel="thumbs"` container inside `<slide-carousel>` for synchronized thumbnail strips.

## Dialog integration

Carousels inside closed `<dialog>` elements defer initialization until the modal opens. Add `data-carousel-start="2"` to the trigger button to open at an exact slide.

## Dynamic re-initialization

After inserting new HTML into the page:

```js
EmblaInit.init(containerElement);
```
