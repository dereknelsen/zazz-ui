---
title: Alert dialog
description: A modal dialog that requires an explicit response to proceed.
---

An alert dialog is a [Dialog](/docs/components/dialog) with a stricter contract: `<dialog class="ui-dialog ui-alert-dialog" role="alertdialog" closedby="none">`. There is no close button and no light dismiss; Cancel or Confirm buttons are the only ways to dismiss it. It composes standard dialog slots (`dialog-content`, `dialog-header`, `dialog-body`, `dialog-footer`) and uses a native `<dialog>` opened with Invoker Commands.

Give the dialog `aria-labelledby` pointing to the heading and `aria-describedby` pointing to the body so the prompt and its consequences are announced together.

## API

| Attribute    | Target             | Values                                              |
| ------------ | ------------------ | --------------------------------------------------- |
| `command`    | Trigger            | `show-modal`; `close` on the Cancel/Confirm buttons |
| `commandfor` | Trigger            | Target `<dialog>` id                                |
| `role`       | `.ui-alert-dialog` | `alertdialog`                                       |
| `closedby`   | `.ui-alert-dialog` | `none`: the alert contract                          |
