---
title: Table
description: Styled semantic HTML tables with striped, grid, and compact variants.
---

Apply `.ui-table` to a standard `<table>` element (`<caption>`, `<thead>`, `<tbody>`, `<tfoot>`, `<tr>`, `<th>`, `<td>`). Rows include hover tints by default. Set `data-state="selected"` on a `<tr>` for selected styling.

Wrap wide tables in `<div class="overflow-x-auto">` for horizontal scrolling.

## API

| Attribute      | Values                                    |
| -------------- | ----------------------------------------- |
| `data-variant` | `alternating`, `grid` (omit = default)    |
| `data-size`    | `sm`                                      |
| `data-layout`  | `fixed` (omit = `table-layout: auto`)     |
| `data-state`   | `selected` (on a `<tr>`)                  |
| `data-side`    | `top` (on the `<caption>`; omit = bottom) |

Override styling tokens globally on `:root` or on an instance (`--table-row-background--hover`, `--table-alternating-background`).
