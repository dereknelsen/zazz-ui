---
title: Password group
description: Password input with built-in show/hide visibility toggle.
---

`.password-group` provides an input group with a trailing ghost button that toggles password visibility. Wrap with `<input-password>` to enhance with JavaScript while remaining fully functional as a masked text input without JS.

## Default

<Preview src="password-group/default" />

## API

| Element / Attribute                   | Target             | Description                                  |
| ------------------------------------- | ------------------ | -------------------------------------------- |
| `<input-password>`                    | Wrapper            | Finds password input and toggles visibility  |
| `.password-group`                     | Container          | Layout for input field and addon button      |
| `[data-slot="password-group-toggle"]` | Button             | Toggles input type between password and text |
| `label-show`                          | `<input-password>` | Accessible label when password is hidden     |
| `label-hide`                          | `<input-password>` | Accessible label when password is shown      |
