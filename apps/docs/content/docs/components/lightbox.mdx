---
title: Lightbox
description: Media lightbox custom element combining an inline gallery, fullscreen dialog, and synchronized thumbnails.
---

`<media-lightbox>` coordinates an inline `<slide-carousel>` gallery with a fullscreen `<dialog>` carousel. Slides open the dialog using `command="show-modal"`. The component syncs slide indices between the inline and fullscreen carousels.

## Markup structure

| Markup                                                              | Placement | Purpose                                          |
| ------------------------------------------------------------------- | --------- | ------------------------------------------------ |
| `<media-lightbox class="lightbox">`                                 | Root      | Coordinates gallery and modal state              |
| `<slide-carousel class="lightbox__stage">`                          | Gallery   | Inline carousel with drag and thumbnail support  |
| `<dialog class="lightbox__dialog">`                                 | Root      | Fullscreen modal container                       |
| `<slide-carousel>`                                                  | Dialog    | Fullscreen carousel initialized when modal opens |
| `command="show-modal"` / `command="close"`                          | Triggers  | Opens and closes dialog using Invoker Commands   |
| `data-carousel="viewport"` / `"container"` / `"slide"` / `"thumbs"` | Children  | Embla layout roles                               |
