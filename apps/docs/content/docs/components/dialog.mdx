Dialogs use native `<dialog class="dialog">` elements. Open from buttons with `command="show-modal"` and `commandfor="<id>"`. Close with `command="close"`. Add `closedby="any"` for light-dismiss on backdrop click.

## API

| Attribute    | Target     | Values                           |
| ------------ | ---------- | -------------------------------- |
| `command`    | Trigger    | `show-modal`, `close`            |
| `commandfor` | Trigger    | Target `<dialog>` id             |
| `data-size`  | `.dialog`  | `article`, `container`, `screen` |
| `closedby`   | `<dialog>` | `any`, `closerequest`, `none`    |
