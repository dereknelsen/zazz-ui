---
title: Input
description: Text inputs with shared field tokens and native validation styling.
---

Inputs use the `.input` class and share `--field-*` design tokens. Validation styles trigger via `:user-invalid` on blur or submit. Wrap in `.field` for label, hint, and error message layouts.
