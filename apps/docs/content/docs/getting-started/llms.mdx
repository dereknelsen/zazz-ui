Zazz includes structured agent skills and reference docs for AI coding assistants. These files define the token system, CSS APIs, and component authoring patterns.

## Available skills

The `zazz` skill lives at [`.claude/skills/zazz/`](https://github.com/dereknelsen/zazz-ui/tree/main/.claude/skills/zazz):

| File                       | Purpose                                         |
| -------------------------- | ----------------------------------------------- |
| `SKILL.md`                 | Entry instructions and system trigger rules     |
| `DESIGN.md`                | Design system principles and token architecture |
| `PATTERNS.md`              | Component authoring patterns and conventions    |
| `references/tokens.md`     | Token reference (scales, roles, metrics)        |
| `references/components.md` | Component markup and variant API reference      |
| `references/apis.md`       | Modern CSS APIs used across the system          |

## AI assistant setup

### Claude

The skill is pre-configured. Claude tools reading `.claude/skills/` load Zazz conventions automatically.

### Other AI assistants

Provide key reference files as context:

1. **`SKILL.md`:** Instructions for using Zazz.
2. **`references/tokens.md`:** Valid token names and semantic roles.
3. **`references/components.md`:** HTML markup patterns for components.

### Plain-text endpoints

- [`/llms.txt`](/llms.txt): Condensed site documentation.
- [`/llms-full.txt`](/llms-full.txt): Complete documentation in plain text.

## Core rules in the skill

- Use the cascade layers (`variables, reset, vendors, legacy, zazz, overrides`, with `components`, `plugins`, `utilities` nested inside `zazz`).
- Use semantic tokens (`--primary`, `--space-md`) over hardcoded pixel/hex values. The spacing scale is `--space-2xs` to `--space-2xl`, step multiples of `--spacing-interval`; utility classes cover `xs` to `xl`.
- For a value off the scale, set a style prop in the `style` attribute (`style="--px: 5; --w-md: 22rem"`) instead of custom CSS; spacing props are step multiples (`--px: 6` is `px-md`).
- Responsive: `@sm:` to `@2xl:` class prefixes and `-sm` to `-2xl` prop suffixes at 40, 48, 64, 80, and 96rem, gated on the `--bp-*` flags of the nearest size container (`--screen-*` for the viewport). Container bands and `data-container` use the same names, with `lg` as the default.
- Apply variants through `data-*` attributes.
- Use `light-dark()` for theme-aware colors.
- Follow token naming conventions (`--ui-{component}-{property}--{state}`).
- Match existing component file structure.
