title: Gap & basis
description: Gap utilities for flex and grid containers, gap-aware flex basis fractions, and coordination variables.
---

`gap-*` controls spacing in flex and grid containers. `basis-*` sets flex basis fractions that automatically account for container gaps.

## Gap utilities

<Preview src="utilities/gap" />

| Class       | Value             |
| ----------- | ----------------- |
| `gap-0`     | `0`               |
| `gap-0.5px` | `0.5px`           |
| `gap-px`    | `1px`             |
| `gap-xs`    | `var(--space-xs)` |
| `gap-sm`    | `var(--space-sm)` |
| `gap-md`    | `var(--space-md)` |
| `gap-lg`    | `var(--space-lg)` |
| `gap-xl`    | `var(--space-xl)` |

The `xs` to `xl` steps are the middle five of the `--space-2xs` to `--space-2xl` scale (step multiples of `--spacing-interval`; see [Spacing](/docs/foundation/utilities/spacing)).

### Open values: use a style prop

For a gap off the scale, set a [style prop](/docs/core-concepts/style-props): `style="--gap: 5"` is `gap: calc(5 * var(--spacing-interval))`, so `--gap: 6` equals `gap-md`. `--gap`, `--gap-x`, and `--gap-y` take `-sm` to `-2xl` responsive suffixes (`--gap-lg: 8`), and `--gap` also sets `--_gap`, so the basis fractions below subtract the prop's gap exactly as they do for `gap-*`.

### Axis-specific gaps

Use `gap-x-*` for `column-gap` and `gap-y-*` for `row-gap`:

```html
<div class="grid grid-cols-3 gap-x-lg gap-y-sm">...</div>
```

## Flex basis fractions

<Preview src="utilities/basis" />

Fraction utilities subtract gap values so child elements fit on a single line:

| Class        | Value                  |
| ------------ | ---------------------- |
| `basis-0`    | `flex-basis: 0`        |
| `basis-auto` | `flex-basis: auto`     |
| `basis-full` | `flex-basis: 100%`     |
| `basis-1/2`  | `(100% - 1 * gap) / 2` |
| `basis-1/3`  | `(100% - 2 * gap) / 3` |
| `basis-1/4`  | `(100% - 3 * gap) / 4` |
| `basis-1/5`  | `(100% - 4 * gap) / 5` |
| `basis-1/6`  | `(100% - 5 * gap) / 6` |

<Callout type="info">
  Set a `gap-*` class or a `--gap` style prop on the flex container to pass the gap value into
  `--_gap`. With neither, `--_gap` defaults to `0px`.
</Callout>

## Gap coordination variables

| Variable   | Default | Set by               | Consumed by                                |
| ---------- | ------- | -------------------- | ------------------------------------------ |
| `--_gap`   | `0px`   | `gap-*`, `--gap`     | `basis-1/2` to `basis-1/6`, auto-fill grid |
| `--_gap-x` | None    | `gap-x-*`, `--gap-x` | `column-gap`                               |
| `--_gap-y` | None    | `gap-y-*`, `--gap-y` | `row-gap`                                  |
