Spacing utilities read the semantic `--space-*` scale and use logical properties (`inline`, `block`).

## The scale

`--space-2xs` to `--space-2xl` are step multiples of `--spacing-interval`, the fluid base unit (`clamp(0.225rem, …, 0.25rem)`, about 3.6px to 4px), so the whole scale scales with the viewport. The classes cover the middle five steps, `xs` to `xl`; `2xs` and `2xl` are tokens for custom CSS and [style props](/docs/core-concepts/style-props).

| Token         | Step        | Multiplier | At 4px |
| ------------- | ----------- | ---------- | ------ |
| `--space-2xs` | `--step-1`  | 1          | 4px    |
| `--space-xs`  | `--step-2`  | 2          | 8px    |
| `--space-sm`  | `--step-4`  | 4          | 16px   |
| `--space-md`  | `--step-6`  | 6          | 24px   |
| `--space-lg`  | `--step-11` | 11         | 44px   |
| `--space-xl`  | `--step-24` | 24         | 96px   |
| `--space-2xl` | `--step-40` | 40         | 160px  |

### Open values: use a style prop

For a step the classes don't cover, set a [style prop](/docs/core-concepts/style-props): `style="--px: 5"` is `padding-inline: calc(5 * var(--spacing-interval))`, so `--px: 6` equals `px-md` and `--mt: -2` is a negative margin. The spacing family has 17 props (`--p`, `--px`, `--py`, `--ps`, `--pe`, `--pt`, `--pb`, `--m`, `--mx`, `--my`, `--ms`, `--me`, `--mt`, `--mb`, `--gap`, `--gap-x`, `--gap-y`), each with `-sm` to `-2xl` responsive suffixes (`--px-md: 8`). Two limits: a prop is a unitless multiplier (`--px: 1rem` is invalid and applies nothing), and `auto` is not a step, so auto margins stay classes (`mx-auto`).

## Padding

<Preview src="utilities/padding" />

| Scope                      | Classes                    | Sets                   |
| -------------------------- | -------------------------- | ---------------------- |
| All sides                  | `p-0`, `p-xs` to `p-xl`    | All four edges         |
| Inline axis (left + right) | `px-0`, `px-xs` to `px-xl` | `padding-inline`       |
| Block axis (top + bottom)  | `py-0`, `py-xs` to `py-xl` | `padding-block`        |
| Top (block-start)          | `pt-0`, `pt-xs` to `pt-xl` | `padding-block-start`  |
| Bottom (block-end)         | `pb-0`, `pb-xs` to `pb-xl` | `padding-block-end`    |
| Left (inline-start)        | `pl-0`, `pl-xs` to `pl-xl` | `padding-inline-start` |
| Right (inline-end)         | `pr-0`, `pr-xs` to `pr-xl` | `padding-inline-end`   |
| Inline start (alias)       | `ps-0`, `ps-xs` to `ps-xl` | `padding-inline-start` |
| Inline end (alias)         | `pe-0`, `pe-xs` to `pe-xl` | `padding-inline-end`   |

`ps-*` / `pe-*` are logical-name aliases of `pl-*` / `pr-*` — identical values, identical declarations. All side classes map to logical edges, so they follow the writing mode.

## Margin

| Scope                      | Classes                                                        |
| -------------------------- | -------------------------------------------------------------- |
| All sides                  | `m-0`, `m-xs` to `m-xl`                                        |
| Inline axis                | `mx-0`, `mx-xs` to `mx-xl`, `mx-auto`                          |
| Block axis                 | `my-0`, `my-xs` to `my-xl`, `my-auto`                          |
| Per side                   | `mt-*`, `mr-*`, `mb-*`, `ml-*` (`0`, `xs` to `xl`, and `auto`) |
| Per side (logical aliases) | `ms-*` (= `ml-*`), `me-*` (= `mr-*`)                           |

### Auto margins

<Preview src="utilities/margin-auto" />

- `mx-auto`: Centers a fixed-width block.
- `ml-auto` / `mr-auto`: Pushes a flex child to the opposite edge.

### Negative margins

| Scope                      | Classes                                           |
| -------------------------- | ------------------------------------------------- |
| All sides                  | `-m-xs` to `-m-xl`                                |
| Inline / block axis        | `-mx-xs` to `-mx-xl`, `-my-xs` to `-my-xl`        |
| Per side                   | `-mt-*`, `-mr-*`, `-mb-*`, `-ml-*` (`xs` to `xl`) |
| Per side (logical aliases) | `-ms-*` (= `-ml-*`), `-me-*` (= `-mr-*`)          |

## Composition variables

Spacing utilities set `@property`-registered variables with `inherits: false`. You can combine an all-sides utility with a single-edge utility:

```html
<!-- md padding on top, bottom, and right; zero on left -->
<div class="p-md pl-0">...</div>
```

<Preview src="utilities/padding-compose" />

| Variable                                           | Syntax                        | Initial | Set by                                                         |
| -------------------------------------------------- | ----------------------------- | ------- | -------------------------------------------------------------- |
| `--_padding-inline-start`, `--_padding-inline-end` | `<length-percentage>`         | `0`     | `p-*`, `px-*`, `pl-*`/`ps-*`, `pr-*`/`pe-*`                    |
| `--_padding-block-start`, `--_padding-block-end`   | `<length-percentage>`         | `0`     | `p-*`, `py-*`, `pt-*`, `pb-*`                                  |
| `--_margin-inline-start`, `--_margin-inline-end`   | `<length-percentage> \| auto` | `0`     | `m-*`, `mx-*`, `ml-*`/`ms-*`, `mr-*`/`me-*`, `-m-*`, `mx-auto` |
| `--_margin-block-start`, `--_margin-block-end`     | `<length-percentage> \| auto` | `0`     | `m-*`, `my-*`, `mt-*`, `mb-*`, `-m-*`, `my-auto`               |
