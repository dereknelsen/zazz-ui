Layout utilities control display mode, positioning, overflow, stacking, and page-level container bands.

## Containers

Place a `.container` as a direct child of `main`, `section`, `header`, `footer`, or `article`. The region becomes a layout grid of width bands, and each direct child of the container is placed into a band. The bands are named after the breakpoint scale (`sm` to `2xl`, 40 to 96rem), with `lg` as the default. See [Layout and containers](/docs/core-concepts/layout) for how the system works and how it differs from a fixed-width container.

```html
<section>
  <div class="container">
    <h1>Title in the default lg band</h1>
    <p>Body copy aligned to the same band.</p>
  </div>
</section>
```

### Container bands

| Band           | Max width                  | Use                                      |
| -------------- | -------------------------- | ---------------------------------------- |
| `sm`           | `--breakpoint-sm` (40rem)  | Narrow column                            |
| `md`           | `--breakpoint-md` (48rem)  | Forms, card layouts                      |
| `lg` (default) | `--breakpoint-lg` (64rem)  | Standard content width                   |
| `xl`           | `--breakpoint-xl` (80rem)  | Wide sections                            |
| `2xl`          | `--breakpoint-2xl` (96rem) | Dashboards and galleries                 |
| `full`         | Region width minus gutters | Edge-aligned rows retaining page gutters |
| `bleed`        | 100% viewport/region width | Full-bleed media and color bands         |

### Default band

`data-container` on the container sets the default band for all children:

```html
<section>
  <div class="container" data-container="xl">
    <h2>Wide section</h2>
    <p>Children align to the xl band.</p>
  </div>
</section>
```

### Child band overrides

`data-container` on a direct child overrides that child only:

```html
<section>
  <div class="container">
    <h1>Title in default band</h1>
    <figure data-container="bleed">
      <img src="/wide.jpg" alt="" />
    </figure>
  </div>
</section>
```

### Responsive variants

`@md:container` is a band container from its breakpoint (48rem) up and a plain block below. `@max-md:container` is the inverse: a container only below the breakpoint, falling back to the element's other classes above it (useful for handing off to a grid). Both take any of the five prefixes, `sm` to `2xl`.

```html
<section>
  <div class="@max-lg:container grid @lg:grid-cols-2 gap-lg">...</div>
</section>
```

### Article reading measure

Add `data-variant="article"` to center content constrained by `ch` units:

```html
<article>
  <div class="container" data-variant="article" data-container="lg">
    <h1>Reading column</h1>
    <p>Constrained to 65ch line length with gutters.</p>
  </div>
</article>
```

| Value          | Measure |
| -------------- | ------- |
| `sm`           | 45ch    |
| `md`           | 50ch    |
| `lg`           | 65ch    |
| `xl` (default) | 70ch    |
| `2xl`          | 75ch    |

### Insets and offsets

Offsets use logical inset properties, so they follow the writing mode. `start-*` / `end-*` are equivalent aliases of `left-*` / `right-*`.

| Class                                    | Declaration                               |
| ---------------------------------------- | ----------------------------------------- |
| `inset-0`                                | `inset: 0`                                |
| `inset-xs` to `inset-xl`                 | `inset: var(--space-{size})`              |
| `top-*` (`0`, `xs` to `xl`)              | `inset-block-start: var(--space-{size})`  |
| `bottom-*` (`0`, `xs` to `xl`)           | `inset-block-end: var(--space-{size})`    |
| `left-*` / `start-*` (`0`, `xs` to `xl`) | `inset-inline-start: var(--space-{size})` |
| `right-*` / `end-*` (`0`, `xs` to `xl`)  | `inset-inline-end: var(--space-{size})`   |

```html
<div class="relative">
  <span class="absolute top-sm right-sm ui-badge" data-variant="primary">New</span>
</div>
```

### Open values: use a style prop

For an offset off the scale, set a [style prop](/docs/core-concepts/style-props): `style="--top: 1rem; --left-md: 2rem; --z: 10"`. `--top`, `--right`, `--bottom`, `--left`, `--inset`, and `--z` pass any value (a length, percentage, `auto`, `anchor()`, an integer for `--z`) to the same logical inset properties, take `-sm` to `-2xl` responsive suffixes, and do not set `position`, so pair them with a position class as above.
