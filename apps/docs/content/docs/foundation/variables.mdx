---

Values in Zazz are CSS custom properties on `:root`. Components consume `var(--token)` without hardcoded values.

```css
/* Update global brand color — a light-dark() pair covers both schemes */
:root {
  --primary: light-dark(oklch(0.6 0.2 145), oklch(0.52 0.17 145));
}
```

## Token tiers

| Tier                   | Description                 | Examples                                                                                         |
| ---------------------- | --------------------------- | ------------------------------------------------------------------------------------------------ |
| Brand & literal scales | Fixed color ramps           | `--primary-50` to `--primary-950`, `--neutral-*`, `--shade-*`, `--tint-*`                        |
| Semantic roles         | Theme-aware colors          | `--background`, `--foreground`, `--primary`, `--muted`, `--border`, `--destructive`              |
| Metrics & systems      | Spacing, typography, shapes | `--gap-*`, `--step-*`, `--font-size-*`, `--radius-*`, `--shadow-*`, `--breakpoint-*`, `--ring-*` |
| Component tokens       | Component-specific hooks    | `--ui-button-background`, `--ui-field-border-color`, `--ui-dialog-radius`                        |

Roles resolve through [`light-dark()`](/docs/core-concepts/dark-mode). Component tokens default to global semantic tokens — or to another component's tokens when two components should stay visually coupled: the shared `--ui-field-*` family (owned by `fields.css`) drives inputs, selects, and textareas, and also the metrics of buttons, toggles, tabs, checkboxes, radios, and badge borders. One `--ui-field-radius` or `--ui-field-block-size` override retunes the whole row of controls together.

Token names mirror the logical CSS property they feed (`--ui-field-block-size`, not `--ui-field-height`), and interactive controls split borders into `-border-width` / `-border-style` / `-border-color` (+ `-border-color--hover` / `--focus`) so any part can be overridden on its own.

## Override scopes

### Global override

Update tokens on `:root` to apply system-wide:

```css
:root {
  --radius-md: 0;
  --primary: light-dark(oklch(0.55 0.18 264), oklch(0.62 0.15 264));
}
```

### Component default override

Reassign component tokens on `:root` to update all instances of a component:

```css
:root {
  --ui-button-radius: var(--radius-full);
}
```

### Instance override

Set tokens inline on a single element:

```html
<button class="ui-button" style="--ui-button-background: var(--secondary)">Secondary</button>
```

## Token families

- **Spacing:** Semantic `--gap-xs` to `--gap-xl` and fluid step scale `--step-0_5` to `--step-96`.
- **Typography:** `--font-size-*`, `--font-weight-*`, `--leading-*`, and `--tracking-*`.
- **Color:** Semantic roles and literal scales. See [Colors](/docs/core-concepts/colors).
- **Radius:** `--radius-none` to `--radius-full`; the `xs`–`xl` steps scale with `--radius-multiplier` (`none` and `full` are literals).
- **Shadow:** `--shadow-xs` to `--shadow-xl`.
- **Layout:** `--breakpoint-xs` to `--breakpoint-xl`, `--gutters`, and reading measures `--article-xs` to `--article-xl`.
- **Motion:** `--spring-easing`, `--spring-duration`, and `--default-transition-*`. The `--default-transition-*` pair is zeroed automatically when `prefers-reduced-motion` is active (the spring tokens keep their values).

## Token source files

Global tokens are defined in `src/base/_variables.css`. Component tokens are declared in each component's stylesheet under `@layer variables`.
