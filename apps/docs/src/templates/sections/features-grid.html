Name the three things it does best

Introduce the features below in one sentence. Lead with the problem they solve together.

  • First feature

    Say what it does for the reader, not how it is built. One or two sentences is plenty.

  • Second feature

    Name a result the reader can picture, like the time it saves or the step it removes.

  • Third feature

    Close with the feature that removes the last doubt, such as security, support, or price.
